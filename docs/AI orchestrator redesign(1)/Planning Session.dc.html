Plan Spec · rev 2 ✓ approved
Scope
Add Google and GitHub OAuth2 login to the checkout service using PKCE authorization code flow, with account linking across providers, Redis-backed sessions (7-day TTL), and cart persistence across the auth redirect.
Approach
Passport.js strategies behind a provider-agnostic auth facade. PKCE verifier stored in a short-lived Redis key keyed to the OAuth state parameter. Account linking resolved at the email level with a merge-on-conflict policy.
Components
Auth facade Provider-agnostic login/logout/refresh interface
Session middleware Redis-backed with sliding-window refresh
Account linker Email-based merge with conflict resolution
Cart bridge Preserves anonymous cart across auth redirect
