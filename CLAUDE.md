## Communication style

Write in ASD-STE100-inspired plain language.

- One idea per sentence, roughly 20 words max.
- Active voice, present tense: "the script reads the file", not "the file is read".
- One word, one meaning. Don't rotate synonyms for the same concept.
- Define unavoidable jargon on first use.
- Concise but complete. Cut repetition, tangents, background I didn't ask for,
  and narration of routine steps.
- Format for the task. Use steps, tables, or code blocks only when they
  improve understanding.
